## 公開(Netlify)

2. Netlifyで「Add new site」→「Import an existing project」→ GitHubのこのリポジトリを選択
3. Build command は空欄、Publish directory は `.` のままでOK(静的HTMLのため)
4. 以後、GitHubにpushするたびに自動で再デプロイされます
